Three launch bugs, all found on a real machine.

**The menu bar icon could go missing and stay missing.** macOS remembers where the icon was
put, in points from the right edge, and hands the value back on the next launch without
checking it still fits. One machine held a position wider than both its displays together,
which drew the icon past the left edge of each: the app was running and working, and
relaunching read the same value again. The stored position is now checked against the width
of every display before the icon is placed, and discarded when it cannot be a position on
any of them. The item also has a name of its own now rather than a generated one, so the
position it saves is under a key that is documented; the icon may sit in a different spot
once after upgrading, and dragging it puts it back.

**Quit Übersicht could quietly do nothing.** The dialog offering to quit Übersicht sent a
polite request that the other app is free to ignore, and nothing checked whether it went.
A shipped Übersicht was seen refusing both that and an AppleScript quit. Gailan now waits,
insists, and says so if the other app is still there, rather than leaving two apps drawing
the same widgets while the dialog implies the matter is settled. The same applies to the
dialog about a second copy of Gailan.

**A dialog could appear with nothing to click.** Both conflict dialogs ran before the menu
bar icon existed, so a dialog waiting behind another window or on another space left an app
with no icon and no dock tile to reach. The icon goes up first.
