### Fixed

- **The menu bar icon could go missing and stay missing.** macOS remembers where the icon was put and restores it without checking it still fits, so a position wider than every display drew the icon off the edge, and relaunching read the same value again. The stored position is now checked before the icon is placed.
- **Quit Übersicht could quietly do nothing.** The request to quit is one the other app may ignore, and nothing checked whether it went. Gailan now waits, insists, and says so if Übersicht is still running. The same goes for a second copy of Gailan.
- **A dialog could appear with nothing to click.** Both conflict dialogs ran before the menu bar icon existed. The icon goes up first.
